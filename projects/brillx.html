02 / BRILLX · 2025 · CAPSTONE

A learning platform designed around intelligent services.

BrillX is a cloud-native SaaS learning platform combining a React frontend, Node.js/Express core backend, Python/FastAPI AI services, MongoDB Atlas, Clerk authentication, RAG document interaction, an AI mentor and adaptive quizzes.

React + ViteNode.jsFastAPIMongoDB AtlasRAGClerk

The problem

Traditional learning systems often follow one path for everyone. BrillX was designed to make content, feedback, mentorship and assessment adapt to the learner.

The architecture

The application separates product logic from AI inference: Node.js/Express owns core APIs and data workflows, while FastAPI handles AI and retrieval workloads.

Feature architecture

01AI MentorConversational tutoring with an ONNX-based Kokoro TTS path and a virtual whiteboard experience.
02PDF RAGDocuments are chunked, embedded with SentenceTransformers and retrieved using similarity search before generation.
03Adaptive quizzesQuizzes can be generated for a topic and followed by a weakness-oriented performance report.
04SecurityClerk provides identity, sessions and RBAC while Mongoose schemas enforce structured data boundaries.

Engineering lesson

The useful part was not adding an LLM endpoint. It was separating inference, retrieval, authentication and product workflows so each subsystem could evolve independently.
