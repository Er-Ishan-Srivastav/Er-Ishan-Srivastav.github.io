04 / ENKRYPTOR · 2024 · SECURITY TOOL

Secure file handling with a usable interface.

A desktop Python application combining PyQt5 with cryptographic file workflows, password-based key derivation, random salts and AES-backed symmetric encryption.

PythonPyQt5AESPBKDF2HMACSHA-256

The problem

Security utilities often trade usability for raw cryptographic control. Enkryptor puts file protection behind a desktop UI while keeping password-derived key handling explicit.

The pipeline

A file enters through the UI, a random salt is generated, PBKDF2HMAC derives a key from the password, the cryptographic engine performs the transformation, and the protected output is written to disk.

Security-oriented decisions

01Key derivationPBKDF2HMAC with SHA-256 turns a user password into a stronger cryptographic key.
02SaltingA random 16-byte salt prevents identical passwords from producing identical derived keys.
03File handlingBinary file processing supports text, images, PDFs and archives without relying on a text-only workflow.
04UXDrag-and-drop, batch processing and visible progress keep the security operation understandable to a non-terminal user.

What it demonstrates

  • Security-aware application design.
  • Desktop UI integration with Python logic.
  • Binary file processing and batch workflows.
  • Separation between UI, controller, cryptographic engine and file handler.

Engineering lesson

Security is part of the workflow design, not a library call at the end. Key derivation, salt handling, file boundaries and user experience all affect the final system.
