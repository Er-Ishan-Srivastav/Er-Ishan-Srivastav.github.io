05 / AI VISION ASSISTANT · DESKTOP AI

Seeing, explaining, and speaking the result.

A desktop accessibility-oriented application combining a live camera, a vision-language model, natural-language interaction and text-to-speech output in a non-blocking PyQt architecture.

PythonPyQt5OpenCVLLaVAPyTorchTransformers

The problem

Understanding a changing visual scene should not require a user to stop, capture, inspect and manually interpret every image. The application turns the camera feed into a conversational interface.

The architecture

Camera capture, AI inference and the desktop UI are separated into workers so heavy model processing does not freeze the interface.

Real-time pipeline

01CaptureOpenCV receives frames from the camera device.
02UnderstandA vision-language model processes the selected image and the user's natural-language question.
03RespondThe application produces a human-readable answer describing or explaining the scene.
04SpeakText-to-speech converts the answer into audio for hands-free consumption.

My contribution

  • System validation and testing.
  • Technical documentation and report work.
  • Integration checks across the desktop application pipeline.

Engineering lesson

For interactive AI, latency is also a UX property. Separating camera capture and inference from the UI makes the model useful without making the application feel frozen.
